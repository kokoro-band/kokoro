# 외부 AI 배치 해석 계획

## 목표와 범위

사용자가 로컬 데모에서 외부 AI를 선택하면 한국어 요청을 Gemini API가 배치 의도로 바꿉니다. 기존 배치 엔진이 좌표와 충돌을 계산하고 사용자가 확인한 뒤 브라우저에 저장합니다. 작은 브라우저 모델로 다시 해석하지 않습니다.

서버 저장 모드의 의도 API는 열린 PR #168과 #174 및 #175의 범위입니다. 이번 이슈 #179는 별도의 해석 API와 로컬 데모 연결만 구현합니다. 여러 동작을 한 번에 처리하거나 도면을 인식하는 기능 및 Groq 연결은 포함하지 않습니다.

## 현재 상태와 책임

웹의 BrowserIntent는 한 가지 동작을 표현하는 JSON입니다. parseBrowserIntent가 응답 형식을 읽고 proposeBrowserIntent가 가구와 빈 자리를 확인해 제안을 만듭니다. 쓰기 큐는 저장과 명령의 실행 순서를 관리하며 제안 확인 전에는 배치를 기록하지 않습니다.

Spring은 API 키를 보관하고 요청 문장과 현재 가구의 카탈로그 ID 및 이름만 제공자에 전달합니다. 서버 카탈로그는 저장소의 공통 규격 파일을 사용합니다. 인증 토큰과 도면 원본 및 공간 좌표는 외부 요청에 포함하지 않습니다.

JSON Schema는 허용 필드와 자료형을 정하는 출력 규칙입니다. Gemini에 이 규칙을 전달하고 반환 결과를 서버와 웹에서 다시 검사합니다. 형식이 맞아도 존재하지 않는 가구나 모순된 동작이면 거절합니다.

## 구현 순서

1. 실제 API와 화면 결과를 확인하는 실패 테스트를 작성합니다.
2. Spring의 POST /api/ai/layout-intent와 Gemini 호출을 추가합니다. 설정이 없으면 호출하지 않으며 자동 재시도는 하지 않습니다.
3. 웹에 외부 AI 선택과 요청 중단을 추가합니다. 기존 의도 검증과 배치 제안 및 확인 흐름을 재사용합니다.
4. 중단과 프로젝트 변경 및 화면 종료에서 요청을 취소하고 늦은 응답을 버립니다.
5. 실제 웹과 Spring 및 임시 PostgreSQL을 실행하는 E2E를 추가합니다. 외부 제공자만 모의 HTTP 서버로 대체합니다.
6. 필수 검사와 desktop 및 narrow E2E를 실행하고 설정과 검증 결과를 문서에 남깁니다.

## 계획 검토 반영

Antigravity를 headless로 한 번 호출하고 GPT가 계획을 보완했습니다. 독립 계획 검토에서 아래 두 사항을 반영했습니다.

- E2E의 웹은 로컬 저장 모드로 실행합니다. 해석 API 주소만 같은 실행에서 시작한 Spring으로 지정합니다. 기존 서버 저장 E2E와 별도 검사 목록을 사용하고 저장 JSON 전체를 비교합니다. CI의 각 화면 작업은 두 검사 명령을 순서대로 실행합니다.
- Gemini 후보는 하나이며 finishReason이 STOP일 때만 승인합니다. 본문은 64KiB 이하로 제한하고 본문 수신까지 포함해 8초 안에 끝나야 합니다. 잘린 응답과 큰 응답 및 지연된 본문을 검사합니다.

## 검증

프론트는 vp check와 vp test 및 vp run build를 실행합니다. 백엔드는 ./mvnw test와 ./mvnw package를 실행합니다. E2E는 두 화면 폭에서 제안 적용과 취소 및 호출 제한과 지연 및 잘못된 응답과 중단 및 재요청과 새로고침 후 저장을 확인합니다.

모의 제공자의 E2E 통과는 실제 Gemini의 한국어 해석 품질을 증명하지 않습니다. 실제 API 키를 설정한 뒤 같은 요청 문장을 화면에서 보내 별도 검증합니다.

## 실행 기록

2026년 10월 4일 계획 검토의 중요한 두 항목을 반영한 뒤 독립 검토가 GREEN을 반환했습니다. 구현 전 웹 테스트는 외부 AI 선택 버튼이 없어 실패했습니다. 서버 테스트는 해석 API의 404로 실패했습니다. 구현 후 같은 검사에서 외부 응답 검증과 승인 전 저장 보존 및 중단 뒤 응답 폐기를 확인했습니다.

실제 웹과 Spring을 연결한 외부 AI E2E는 desktop 8개와 narrow 8개가 재시도 없이 통과했습니다. 외부 제공자는 모의 HTTP 서버이며 실제 키는 사용하지 않았습니다. 전송 문맥과 회전 및 상대 배치와 대상 선택 후 API 재호출 방지 및 취소와 오류 뒤 재요청과 새로고침 후 저장을 확인했습니다.

첫 CI 실행 37201418527에서는 두 화면의 중단 검사가 실패했습니다. 제공자의 250ms 응답이 클릭보다 먼저 끝나 중단 버튼이 사라졌습니다. 테스트 서버가 응답을 보류하고 중단 확인 후에 응답을 반환하도록 수정했습니다. 지연 검사는 실제 서버와 같은 8초 제한을 사용합니다. 수정 후 로컬에서 두 화면의 16개 검사가 다시 통과했습니다.

프론트 전체 테스트는 50개 파일의 745개가 통과했습니다. vp check와 E2E 타입 검사 및 빌드도 통과했습니다. 백엔드의 ./mvnw test와 ./mvnw package도 통과했으며 최종 패키지 검사는 203개를 실행했습니다. 기존 브라우저 AI E2E 24개도 통과했습니다. 대기열에 있는 요청을 중단해도 HTTP 호출이 시작되던 실패를 테스트로 확인하고 수정 후 호출하지 않는 결과를 확인했습니다. 빌드의 기존 큰 번들 경고는 남습니다. 실제 Gemini의 한국어 품질과 운영 배포 및 헤드셋 검증은 이번 기록에 포함하지 않습니다.
