# 시스템 구조

## 프로젝트 경계

### frontend

사용자 로그인과 시간 선택과 좌석 예약과 세션 기록을 담당합니다. Unity Web 빌드를 실행하고 로그인 토큰과 예약 식별자를 Unity에 전달합니다. 카메라 기반 존재 감지는 브라우저 안에서만 수행합니다.

### backend

좌석 예약과 착석과 세션 시간을 확정합니다. 영구 데이터는 PostgreSQL에 저장하고 현재 아바타 위치와 접속 상태는 WebSocket으로 전달합니다. 음성 서비스 토큰은 사용자의 현재 구역과 권한을 확인한 뒤 발급합니다.

### unity

3D 공간과 아바타 이동과 좌석 상호작용과 원격 아바타 표시를 담당합니다. 로그인이나 예약 화면을 다시 구현하지 않습니다.

## 상태 소유권

| 상태 | 최종 소유자 | 저장 방식 |
|---|---|---|
| 사용자와 예약 | backend | PostgreSQL |
| 착석과 집중 세션 | backend | PostgreSQL |
| 아바타 위치 | backend 실시간 세션 | 메모리와 WebSocket |
| 카메라 영상 | frontend | 저장하지 않음 |
| 사람 존재 결과 | backend | 마지막 상태와 시각만 저장 |
| 음성 미디어 | 음성 서비스 | 애플리케이션에서 녹음하지 않음 |

## 첫 번째 수직 기능

1. 프론트엔드에서 시간과 좌석을 고릅니다.
2. 백엔드가 중복 예약을 검사하고 예약을 생성합니다.
3. 프론트엔드가 Unity에 예약 문맥을 전달합니다.
4. Unity가 예약 좌석을 강조합니다.
5. 사용자가 앉으면 백엔드가 예약을 활성 세션으로 변경합니다.
