# 가구 배치 검증

가구의 바닥면 전체가 공간 외곽 안에 있어야 합니다. 네 꼭짓점만 들어가도 변이 오목한 빈 공간을 가로지르면 저장하지 않습니다. 회전된 가구도 같은 기준으로 검사합니다.

벽은 중심선과 두께로 계산한 사각형입니다. 내부 벽과 외곽 벽 모두 가구 바닥면과 겹치면 거부합니다. 문이나 창이 있더라도 벽 전체를 통과할 수 있는 것으로 처리하지 않습니다. 현재 가구 계약에 높이가 없어서 보수적으로 판단하는 정책입니다.

문 앞에는 문 폭을 따라 벽 표면에서 양쪽으로 각각 0.8m의 여유 공간을 둡니다. 이 값은 코코로의 제품 규칙이며 건축 법규나 안전 인증 수치가 아닙니다. 창문에는 문 여유 공간 규칙을 적용하지 않습니다.

면적이 겹치지 않고 경계에 닿기만 하는 배치는 허용합니다. 계산 오차를 줄이기 위해 공간 포함 검사에서는 0.0000001m의 오차를 허용합니다.

## 오류 응답

HTTP 400 응답의 `detail`은 사용자 안내입니다. 화면에서 충돌 대상을 표시할 때는 이름을 해석하지 않고 `code`와 `furnitureIds`를 사용합니다.

| code | 뜻 | 추가 식별자 |
|---|---|---|
| OUTSIDE_ROOM | 바닥면이 공간 외곽을 벗어남 | furnitureIds |
| FURNITURE_OVERLAP | 가구끼리 겹침 | 두 가구의 furnitureIds |
| WALL_COLLISION | 벽 두께 영역을 침범함 | furnitureIds와 wallId |
| DOOR_CLEARANCE | 문 앞 여유 공간을 침범함 | furnitureIds와 wallId와 openingId |
| DUPLICATE_FURNITURE_ID | 같은 가구 식별자가 중복됨 | furnitureIds |

지원하지 않는 카탈로그와 잘못된 좌표도 400으로 거부합니다. 배치는 최대 200개입니다. 하나라도 유효하지 않으면 배치와 공간 저장 전체가 취소되며 기존 상태가 유지됩니다. 기존 잘못된 데이터도 조회는 가능하지만 다음 저장에서는 이 검사를 통과해야 합니다.

좌표 후보를 반복 검사하는 AI 배치에서는 카탈로그 규격을 한 번 읽어 고정합니다. 후보마다 DB를 다시 조회하지 않습니다. 규격과 가격은 예제 데이터이며 실제 제품의 설치 가능성을 보증하지 않습니다.
