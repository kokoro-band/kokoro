# 가구 정보 수집과 서버 등록

## 확보한 범위

2026년 9월 26일 Kenney 공식 사이트의 Furniture Kit 압축 파일을 내려받았습니다. 압축 안의 라이선스 파일에는 Furniture Kit 2.0과 CC0가 명시되어 있습니다. GLB 모델 140개 전부의 원본 경로와 파일 크기 및 SHA-256을 기록했습니다. SHA-256은 파일 내용이 같은지 확인하는 값입니다.

- [원본 페이지](https://kenney.nl/assets/furniture-kit)
- [실제 수집한 압축 파일](https://kenney.nl/media/pages/assets/furniture-kit/440e0608a4-1677580847/kenney_furniture-kit.zip)
- 목록과 수집일 및 압축 파일의 SHA-256은 `docs/contracts/furniture-source-assets.json`에 있습니다.

기존 서비스의 8개 GLB 모두 공식 압축 파일의 대응 모델과 SHA-256이 일치했습니다. 모델을 다시 만들거나 다른 공급자의 모델로 교체하지 않았습니다.

## 실제 배치 가능한 가구

현재 배치 카탈로그는 검토된 8종입니다. 클라우드 소파와 모스 소파 및 오크 테이블과 라운드 테이블 및 셸 체어와 샌드 체어 및 올리브 화분과 아크 플로어 램프가 있습니다.

기존 ID와 폭과 깊이 및 예제 가격은 유지했습니다. 전체 정보는 `docs/contracts/furniture-catalog.json`에 있습니다. 각 항목에는 모델 출처와 원본 이름 및 SHA-256과 라이선스를 추가했습니다.

140개 원본 모델의 목록을 확보한 것과 140개를 모두 사용 가능한 가구로 등록한 것은 다릅니다. 나머지 모델에는 벽과 문 및 생활용품도 있습니다. 아직 배치 규격과 한국어 이름을 검토하지 않은 모델은 자연어 명령의 가구 후보로 노출하지 않습니다.

## 가격과 치수의 의미

`dimensionKind=example`은 배치용 예제 규격이라는 뜻입니다. 실제 판매 상품을 실측한 값이 아닙니다. GLB의 시각적 높이도 실제 가구 높이로 간주하지 않습니다.

`priceKind=example`은 화면에 보여주는 예제 가격이라는 뜻입니다. 실시간 판매 가격이나 이사 비용이 아닙니다. 상용 상품의 이름과 가격 및 재고를 크롤링했다고 표시하지 않습니다.

## 서버 저장

서버를 시작하면 등록 원본이 PostgreSQL의 `furniture_catalog`에 들어갑니다. 140개 원본 모델의 목록은 `furniture_source_assets`에 들어갑니다. 같은 원본으로 다시 시작해도 중복 행을 만들거나 수집 시각을 바꾸지 않습니다. 원본이 바뀐 항목만 갱신합니다.

`GET /api/furniture-catalog`는 가구 8종의 모든 정보와 공통 출처 및 원본 모델 수를 반환합니다. 서버의 배치 검증기도 이 DB에서 가구 규격을 조회합니다. 존재하지 않는 ID는 거부합니다. 운영 프로필에서는 기존 인증 정책을 따릅니다.

## 검증

`FurnitureRegistryTest`는 PostgreSQL에서 초기 등록과 반복 시작 및 API의 전체 필드와 미등록 ID 거부를 검사합니다. 모델 파일은 수집한 공식 압축 파일과 직접 대조했습니다. 실제 쇼핑몰 가격과 실제 가구 실측은 수행하지 않았습니다.
